# 微信公众号

目前定为每周4篇，周一、周三、周五、周日，当天的15:00发。

优先选题：AI信息咨询、好用的AI工具、AI应用案例

发超过10篇原创文章后，可以考虑也再做一下其他平台的，小红书，知乎什么的，互相引流。

发了5篇以后，可以做点微付费投流。

后续发的文章都要收录记录，最后做整合，ai工具包-具体实践项目等。

维护粉丝社群-微信或qq群

在文章中可以加入互动元素-投票-问答-评论引导等

**注意事项**：规避敏感词（如 “分享”“转发”“朋友圈”），多用 “邀请”“推荐”“助力” 等词，遵守平台规则
