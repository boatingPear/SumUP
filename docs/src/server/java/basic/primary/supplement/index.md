## Idea快捷键

### 查看接口实现类

> Ctrl+Alt+B

选中一个方法，按键Ctrl+Alt+B即可查看实现此接口的实现类

![image-20230321143750637](../../assets/e895b0c6ed06357d1e49ae572157caa7.png)

### 图标小细节

Ctrl+F12可以查看当前类中的状态，例如成员方法，成员属性等等

![image-20230424201934606](../..\assets\5e16b16cf848691116950ef6a8979e98.png)

::: tip 

C表示类，M表示方法，F表示常量或，静态成员变量，->表示继承，T表示重写

:::
