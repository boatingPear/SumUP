# 第四天：肩（前束 + 中束 + 后束）

> **训练目标**：三角肌前束、中束、后束 —— 打造立体饱满的「3D 肩」
> **训练时长**：~45 分钟 | **组间休息**：主项 75-90s，辅助 60s
> **注意事项**：肩关节是最容易受伤的关节之一，所有动作强调控制而非大重量。有肩部不适时，优先缩减重量、增加次数

---

## 一、练前热身（5-8 分钟）

> 目标：充分激活肩袖肌群，润滑肩关节——肩日热身比其他日子更关键！

### 1.1 弹力带肩外旋

![肩外旋](gifs/cable-external-rotation.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 肘部夹紧 90°，手臂向外旋转，肩袖后侧收紧 |
| **伸展** | 缓慢回到起始位，肩袖前侧拉伸 |

- 弹力带绑在固定物上，肘部夹紧身体呈 **90°**
- 向外旋转手臂，感受肩袖后侧发力
- **3 组 × 15 次/侧**（肩日多加一组！），慢速控制

### 1.2 弹力带反向飞鸟

![弹力带反向飞鸟](gifs/band-reverse-fly.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 向两侧拉开，后束和上背中部收紧 |
| **伸展** | 缓慢合拢，感受上背的拉伸 |

- 双手握住弹力带，手臂微屈，向两侧拉开
- 感受**后束和上背中部**的收缩
- **2 组 × 15 次**

### 1.3 弹力带面拉（Face Pull）

- 弹力带固定在面部高度，正握拉向面部
- 拉到底时手掌外旋（拇指向后），肘部向外打开
- **2 组 × 15 次**
- 🎯 **面拉是肩日热身的核心！**激活后束的同时稳定肩关节

### 1.4 手臂画圈（肩关节润滑）

- 双臂侧平举（或稍低），做小幅度画圈
- 顺时针 10 次 + 逆时针 10 次
- **1-2 组**，幅度逐渐增大

---

## 二、正式训练（~35 分钟）

> **💡 训练安排说明**
>
> 肩日按照**前束 → 中束 → 后束**的顺序训练：
> - **前束**：推举 + 前平举，打造肩部前侧的饱满度
> - **中束**：侧平举，决定肩膀宽度的关键
> - **后束**：反向飞鸟/面拉，改善圆肩、平衡肩部发展
>
> ⚠️ **全程控制优先**：肩关节不是承重关节，**所有动作慢速控制，不要借力甩动**。

---

### 🟦 A1. 哑铃推举（Dumbbell Shoulder Press）— 主项

![器械推肩](gifs/lever-shoulder-press.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 推起哑铃至头顶，三角肌收紧 |
| **伸展** | 慢速下放至耳朵高度，三角肌被拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 10-12 次 |
| **RPE** | 7-8 |
| **组间休息** | 75-90 秒 |

> ⚠️ **肩部保护提示**：如果推举时肩关节有刺痛或弹响伴随疼痛 → **立即停止**，改用更轻的重量或跳过推举，多做两组侧平举。

**动作讲解**：
1. 坐于凳子上（最好有靠背），双手持哑铃置于肩膀高度
2. 掌心朝前，肘部在身体前方（不是完全侧开）
3. 上推时哑铃向头顶正上方移动，**不要完全锁死肘关节**
4. 推到顶端时哑铃不要相碰
5. 下放时控制（2-3 秒），手肘下放到约耳朵高度即可
6. 全程**核心收紧，背部贴紧靠背**

> 🎯 **重点关注**：哑铃推举比杠铃推举对手腕和肩关节更友好（手腕可以自然旋转）。**如果今天肩膀感觉不好，用轻重量做 15-20 次高次数即可**。

---

### 🟦 A2. 哑铃前平举（Dumbbell Front Raise）— 前束

| 阶段 | 说明 |
|------|------|
| **收缩** | 手臂抬起至与地面平行或略高，前束收紧 |
| **伸展** | 慢速下放，前束被拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 10-12 次 |
| **RPE** | 6-8 |
| **组间休息** | 60 秒 |

**动作讲解**：
1. 站姿，双手持哑铃放于大腿前方，掌心朝向身体
2. 手臂微屈（不要锁死），将哑铃向前上方抬起
3. 抬到与肩同高或略高于肩膀
4. 顶峰收缩前束 1 秒，慢速下放（2-3 秒）
5. **不要借力摆动身体**

> 🎯 **重点关注**：前束在推胸日已经有参与，所以前平举用轻重量 + 高控制即可。**交替做（单手）可以减少借力**。

---

### 🟩 B1. 哑铃飞鸟 / 侧平举（Lateral Raise）— 中束

![哑铃侧平举](gifs/dumbbell-lateral-raise.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 手臂抬起至与地面平行，三角肌中束收紧 |
| **伸展** | 慢速下放，感受中束的拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 10-12 次 |
| **RPE** | 6-8 |
| **组间休息** | 60 秒 |

**动作讲解**：
1. 双手持轻哑铃（**2-5kg 起步**），手臂微屈
2. 从身体两侧抬起至与地面平行，想象**倒水壶**——小拇指侧略高
3. 顶峰保持 1 秒，慢速下放（2-3 秒）
4. **不要借力摆动！**抬起时肘部先于手腕启动
5. 全程保持肩胛骨稳定，不要耸肩

> 🎯 **重点关注**：侧平举是最容易借力的动作。用 2kg 做到完美控制，比用 8kg 甩上去有效 10 倍。**中束是肩膀宽度的关键**——这个动作值得花时间打磨。

---

### 🟩 B2. 蝴蝶机反向飞鸟 / 绳索面拉（二选一）— 后束

> 💡 **两个动作选一个做**，建议交替使用，给后束不同的刺激角度。

---

#### 选项一：蝴蝶机反向飞鸟（Pec Deck Reverse Fly）

![哑铃反向飞鸟](gifs/dumbbell-reverse-fly.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 手臂向后展开，后束收紧，肩胛骨后夹 |
| **伸展** | 慢速回程，后束被拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 10-12 次 |
| **RPE** | 6-8 |
| **组间休息** | 60 秒 |

**动作讲解**：
1. 坐在蝴蝶机上，调整座椅使握把与肩膀同高
2. 手臂微屈，向正后方展开（不是向两侧）
3. 顶峰时**肩胛骨用力夹紧**，感受后束收缩
4. 保持顶峰 1 秒，慢速回程（2-3 秒）
5. **不要耸肩，不要用上背代偿**

> 🎯 **重点关注**：后束是改善圆肩的关键！后束弱 → 肩胛骨前引 → 圆肩。蝴蝶机轨迹固定，比哑铃反向飞鸟更容易找到后束发力感。

---

#### 选项二：绳索面拉（Cable Face Pull）

| 阶段 | 说明 |
|------|------|
| **收缩** | 拉向面部，手掌外旋，后束和上背收紧 |
| **伸展** | 慢速放回，肩袖被拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 10-12 次 |
| **RPE** | 6-8 |
| **组间休息** | 60 秒 |

**动作讲解**：
1. 站于龙门架前，绳索调至面部高度
2. 正握绳索（拇指朝向自己），向面部拉
3. 拉到脸前时手掌外旋（拇指向后），肘部向外打开
4. 顶峰时感受**后束 + 上背 + 肩袖**的全面收缩
5. 慢速放回，手臂不完全伸直

> 🎯 **重点关注**：面拉不仅是后束训练，更是**肩关节健康的保障动作**。每个训练日热身都在做，肩日加一组正式训练的面拉，给后束更多刺激。

---

## 三、练后拉伸（5 分钟）

> 目标：放松三角肌三束，保持肩关节灵活性

### 3.1 肩前束拉伸

![胸部与肩前拉伸](gifs/chest-shoulder-stretch.gif)

| 阶段 | 说明 |
|------|------|
| **拉伸** | 手扶墙/门框，身体前倾旋转，肩前束和胸肌被拉长 |

- 手扶墙或门框，身体前倾并向外旋转
- 感受三角肌前束和胸肌的拉伸
- **每侧保持 30 秒 × 2 组**

### 3.2 肩后束拉伸

- 一只手臂横过胸前，另一只手勾住肘部轻轻拉向身体
- 感受后束和肩袖后侧的拉伸
- **每侧保持 30 秒 × 2 组**

### 3.3 肩中束拉伸

- 一只手臂向对侧斜下方伸展
- 另一只手轻压肘部加深拉伸
- **每侧保持 30 秒 × 2 组**

### 3.4 背阔肌拉伸

![背阔肌拉伸](gifs/kneeling-lat-stretch.gif)

| 阶段 | 说明 |
|------|------|
| **拉伸** | 臀部向后坐，背阔肌被充分拉开 |

- 跪姿或站姿，双手抓住固定物，臀部向后坐
- **每侧保持 30 秒 × 2 组**

---

## 📌 肩日小贴士

- **控制 > 重量**：肩关节是球窝关节，灵活性好但稳定性差，**所有动作宁轻勿重**
- **后束不能忽视**：后束是大多数人最弱的部分，也是改善圆肩的关键
- **中束 = 宽度**：如果你想要「看起来更宽」，中束训练（侧平举）是最值得投入的动作
- **肩疼立即停**：推举时有关节刺痛或弹响伴随疼痛 → 立刻停止，降级为前平举+侧平举
- **呼吸**：推起时呼气，下放时吸气
- **渐进超负荷**：肩部小肌群进步慢，不要急于加重量——先增加次数（从 10 次到 12 次再到 15 次），再考虑加重量
