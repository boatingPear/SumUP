# 第一天：拉日（背部 + 后束 + 二头）

> **训练目标**：背阔肌、中上背、三角肌后束、肱二头肌
> **训练时长**：~60 分钟 | **组间休息**：主项 90s，辅助 60s
> **注意事项**：拉日优先于推日——背部力量是矫正圆肩驼背的关键

---

## 一、练前热身（5-8 分钟）

> 目标：激活肩袖、活动胸椎、预热背部肌群

### 1.1 弹力带肩外旋

![肩外旋](gifs/cable-external-rotation.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 肘部夹紧 90°，手臂向外旋转，肩袖后侧收紧 |
| **伸展** | 缓慢回到起始位，肩袖前侧拉伸 |

- 弹力带绑在固定物上，肘部夹紧身体呈 **90°**
- 向外旋转手臂，感受肩袖后侧发力
- **2 组 × 15 次/侧**，慢速控制

### 1.2 弹力带反向飞鸟

![弹力带反向飞鸟](gifs/band-reverse-fly.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 向两侧拉开，后束和上背中部收紧 |
| **伸展** | 缓慢合拢，感受上背的拉伸 |

- 双手握住弹力带，手臂微屈，向两侧拉开
- 感受**后束和上背中部**的收缩
- **2 组 × 15 次**，顶峰收缩保持 1 秒

### 1.3 弹力带面拉（Face Pull）

- 弹力带固定在面部高度，正握拉向面部
- 拉到底时手掌外旋（拇指向后），肘部向外打开
- **2 组 × 15 次**
- 🎯 **面拉是矫正圆肩的王牌动作，每天必做！**

### 1.4 辅助引体向上（可选激活）

![辅助引体向上](gifs/band-assisted-pull-up.gif)

- 用弹力带辅助或器械辅助
- **2 组 × 5-8 次**，感受背阔肌发力，不是纯靠手臂

## 二、正式训练（~45 分钟）

> **💡 A1/A2、B1/B2、C1/C2 是什么意思？**
>
> 同字母的**全部都要练**，不是选一个。这是**超级组（Super Set）** 配对交替做：
> ```
> A1（做完1组）→ 休息 → A2（做完1组）→ 休息 → A1（第2组）→ 休息 → A2（第2组）→ ……
> ```
> 这样安排能**节约时间**（交替做省去等待肌肉恢复的时间），同时让同一肌群得到更集中的刺激。
>
> **详细说明**：
> - **A 组**（主项，4 组）：大重量复合动作，练最大力量
> - **B 组**（辅助，3 组）：轻重量针对性训练，增加训练量
> - **C 组**（收尾，3 组）：孤立动作，榨干最后一点力

### 🟦 A1. 高位下拉（Lat Pulldown）— 主项

![高位下拉](gifs/lat-pulldown.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 下拉至锁骨高度，背阔肌收紧，肩胛骨下沉 |
| **伸展** | 慢速放回，背阔肌被充分拉开 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 8-12 次 |
| **RPE** | 7-9 |
| **握法** | 宽握（比肩宽 1.5 倍） |
| **组间休息** | 90 秒 |

**动作讲解**：
1. 坐稳，大腿卡在垫子下，**挺胸沉肩**
2. 正握横杆，握距约为肩宽的 1.5 倍
3. 下拉时**想象肘部向下向后拉**，先启动肩胛骨下沉，再带动手臂
4. 拉到锁骨/上胸高度，顶峰收缩挤压背部 1 秒
5. 慢速放回（2-3 秒），感受背阔肌被拉伸
6. 身体不要过度后仰（后仰角度 < 15°）

> 🎯 **重点关注**：很多人用手臂拉而背部不动——如果你发现二头比背部先疲劳，减轻重量重新找发力感。**先夹肩胛，再拉手臂**。

---

### 🟦 A2. 坐姿绳索划船（Seated Cable Row）— 主项

![坐姿绳索划船](gifs/cable-rope-seated-row.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 拉向腹部，肘部向后，肩胛骨夹紧 |
| **伸展** | 慢速放回，手臂不完全伸直，保持背部张力 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 10-12 次 |
| **RPE** | 7-9 |
| **组间休息** | 90 秒 |

**动作讲解**：
1. 坐于划船凳上，双脚踩稳踏板，膝盖微屈
2. 背部保持直立，**不弯腰、不前倾**
3. 拉向腹部时，**肘部贴近身体向后滑**，肩胛骨夹紧
4. 顶峰收缩 1 秒，想象背部中间夹一支笔
5. 慢速放回（2 秒），手臂不完全伸直以保持背部张力

> 🎯 **重点关注**：全程**背部始终挺直**！弯腰是划船中最常见的错误，容易伤腰。

---

### 🟩 B1. 哑铃俯身划船（Bent Over Row）— 辅助

![哑铃俯身划船](gifs/dumbbell-bent-over-row.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 哑铃拉向腰部，背部收紧，肘部贴近身体 |
| **伸展** | 手臂缓慢下放，背阔肌被拉长 |

| | |
|------|------|
| **组数 × 次数** | 3 组 × 10-12 次/侧 |
| **RPE** | 7-8 |
| **组间休息** | 60-90 秒 |

**动作讲解**：
1. 单手撑凳，同侧膝跪凳，另一手持哑铃
2. 背部与地面接近平行，保持中立
3. 将哑铃拉向腰部，**肘部贴近身体**
4. 顶峰收缩 1 秒，缓慢下放

> 🎯 **重点关注**：这个动作对单侧背部发展极好，可以发现并纠正左右不平衡。

---

### 🟩 B2. 哑铃反向飞鸟（Reverse Fly）— 后束

![哑铃反向飞鸟](gifs/dumbbell-reverse-fly.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 手臂向两侧抬起，后束收紧，拇指指向天花板 |
| **伸展** | 慢速下放，后束被拉伸 |

| | |
|------|------|
| **组数 × 次数** | 3 组 × 12-15 次 |
| **RPE** | 6-8 |
| **组间休息** | 60 秒 |

**动作讲解**：
1. 坐在凳子上，俯身至胸部接近大腿，双手持轻哑铃（**2-4kg 起步**）
2. 手臂微屈（不要锁死），向两侧抬起
3. 想象**拇指指向天花板**，感受后束收缩
4. 顶峰保持 1 秒，慢速下放

> 🎯 **重点关注**：后束是改善圆肩的关键！**后束弱 → 肩胛骨前引 → 圆肩**。重量不要大，靠控制和次数。

---

### 🟪 C1. 直臂下压（Straight Arm Pulldown）— 背阔肌收尾

![直臂下压](gifs/cable-straight-arm-pulldown.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 下压至大腿前，背阔肌收紧 |
| **伸展** | 回程不超过肩高，背阔肌被拉伸 |

| | |
|------|------|
| **组数 × 次数** | 3 组 × 12-15 次 |
| **RPE** | 6-8 |
| **组间休息** | 60 秒 |

**动作讲解**：
1. 站于高位龙门架前，双手正握直杆
2. 手臂基本伸直（微屈不锁死），从肩高位置向下压至大腿前
3. 发力时**想象背阔肌收缩**，不是耸肩下压
4. 回程控制（2 秒），手臂不超过肩高

> 🎯 **重点关注**：全程手臂角度不变，靠**背阔肌发力**不是靠身体下压。

---

### 🟪 C2. 哑铃弯举（Biceps Curl）— 二头

![哑铃弯举](gifs/dumbbell-biceps-curl.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 弯举至顶峰，二头肌收紧 |
| **伸展** | 慢速下放，二头肌被拉长，离心控制 |

| | |
|------|------|
| **组数 × 次数** | 3 组 × 10-12 次/侧 |
| **RPE** | 7-8 |
| **组间休息** | 60 秒 |

**动作讲解**：
1. 站姿或坐姿，双手持哑铃，掌心朝前
2. 肘部固定在大腿或身体两侧，**不要摆动借力**
3. 弯举至顶峰，挤压二头肌 1 秒
4. 慢速下放（2-3 秒），离心过程比向心更重要

> 🎯 **重点关注**：如果身体开始晃 → 重量太大。**控制和离心比重量更重要**。

---

### 🟪 C3. 绳索弯举（Cable Curl）— 二头收尾

![绳索弯举](gifs/cable-curl.gif)

| | |
|------|------|
| **组数 × 次数** | 3 组 × 12-15 次 |
| **RPE** | 6-8 |
| **组间休息** | 45-60 秒 |

**动作讲解**：
1. 站于低位龙门架前，双手正握直杆/绳索
2. 肘部贴紧身体两侧，弯举至肩高
3. 慢速下放，保持二头持续张力

> 🎯 **重点关注**：绳索在整个行程中都提供阻力，是二头肌很好的收尾动作。

## 三、练后拉伸（5 分钟）

> 目标：放松背部肌群，打开胸椎，改善体态

### 3.1 背阔肌拉伸

![背阔肌拉伸](gifs/kneeling-lat-stretch.gif)

| 阶段 | 说明 |
|------|------|
| **拉伸** | 臀部向后坐，双手抓住固定物，背阔肌被充分拉长 |

- 跪姿或站姿，双手抓住固定物，臀部向后坐
- 感受背阔肌/大圆肌的拉伸
- **每侧保持 30 秒 × 2 组**

### 3.2 上背拉伸

![上背拉伸](gifs/upper-back-stretch.gif)

| 阶段 | 说明 |
|------|------|
| **拉伸** | 双手交叉于胸前，拱背含胸，肩胛骨之间的肌肉被拉长 |

- 双手交叉于胸前，拱背含胸
- 感受肩胛骨之间的拉伸
- **保持 30 秒 × 2 组**

### 3.3 胸背拉伸

![胸背拉伸](gifs/back-pec-stretch.gif)

| 阶段 | 说明 |
|------|------|
| **拉伸** | 双手背后交叉，肩胛骨后夹，胸腔打开，胸肌被拉伸 |

- 双手背后交叉，肩胛骨向后夹紧
- 同时抬头挺胸，打开胸腔
- **保持 20 秒，做 3 次**

---

## 📌 拉日小贴士

- **拉 > 推**：背部训练量始终大于胸部，平衡前后肌力，改善圆肩
- **先夹肩胛，再拉手臂**：所有拉类动作都先启动肩胛骨
- **肘部轨迹**：划船类动作肘部贴近身体（练背阔肌），手肘打开（练上背/后束）
- **呼吸**：发力（拉）时呼气，回程（放）时吸气
- **渐进超负荷**：记录高位下拉和划船的主项重量，每周小幅增加
