# 第二天：胸 + 肩前束 + 肱三头

> **训练目标**：胸大肌（中胸+上胸）、三角肌前束、肱三头肌
> **训练时长**：~50 分钟 | **组间休息**：主项 90s，辅助 60s
> **注意事项**：有轻度肩部不适，推胸时注意肩关节保护。肩疼立即停止，降低重量或调整幅度

---

## 一、练前热身（5-8 分钟）

> 目标：激活肩袖、打开胸椎、预热上肢推类肌群

### 1.1 弹力带肩外旋

![肩外旋](gifs/cable-external-rotation.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 肘部夹紧 90°，手臂向外旋转，感受肩袖后侧收紧 |
| **伸展** | 缓慢回到起始位，感受肩袖前侧的轻微拉伸 |

- 弹力带绑在固定物上，肘部夹紧身体呈 **90°**
- 向外旋转手臂，感受肩袖后侧发力
- **3 组 × 15 次/侧**（推日多加一组保护肩袖），慢速控制

### 1.2 胸部动态拉伸

![胸部动态拉伸](gifs/dynamic-chest-stretch.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 双手向后展开，胸肌收缩 |
| **伸展** | 双手向前合拢，感受胸肌拉伸 |

- 双手向两侧展开，动态向后伸展
- 感受胸肌和肩前部的拉伸
- **1 组 × 10 次**，逐渐加大幅度

### 1.3 弹力带反向飞鸟

![弹力带反向飞鸟](gifs/band-reverse-fly.gif)

- 双手握住弹力带，手臂微屈，向两侧拉开
- 激活**后束和上背中部**，推前激活后侧帮助稳定肩胛骨
- **2 组 × 15 次**

### 1.4 弹力带面拉（Face Pull）

- 弹力带固定在面部高度，正握拉向面部
- 拉到底时手掌外旋（拇指向后），肘部向外打开
- **2 组 × 15 次**
- 🎯 **面拉是对抗圆肩的第一动作，推日必做！**

## 二、正式训练（~38 分钟）

> **💡 训练安排说明**
>
> 本日采用**超级组（Super Set）** 配对训练：
> ```
> A1（做完1组）→ 休息 → A2（做完1组）→ 休息 → A1（第2组）→ ……
> ```
>
> - **A 组**（主项，4 组）：杠铃+器械推胸，打造胸肌厚度
> - **B 组**（收尾，4 组）：三头肌孤立训练

### 🟦 A1. 仰卧杠铃推胸（Barbell Bench Press）— 主项

![器械推胸](gifs/lever-chest-press.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 推起杠铃至手臂接近伸直，胸肌收紧 |
| **伸展** | 下放杠铃至胸部上方，胸肌被拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 8-10 次 |
| **RPE** | 7-9 |
| **握距** | 略宽于肩（约 1.5 倍肩宽） |
| **组间休息** | 90 秒 |

> ⚠️ **肩部保护**：如果杠铃推胸时肩关节不适 → 立刻改为器械推胸，轨迹固定更安全。

**动作讲解**：
1. 仰卧在平板凳上，眼睛位于杠铃正下方
2. 双脚踩实地面，**肩胛骨后收下沉**贴紧凳子
3. 握距略宽于肩，起杠后杠铃位于胸部正上方
4. 下放至胸部下缘（乳头线附近），**手肘与身体呈约 45-60°**（不要打得太开）
5. 推起时胸肌发力，手臂接近伸直但不锁死肘关节
6. 全程**肩胛骨保持后收**，不要耸肩

> 🎯 **重点关注**：杠铃推胸是胸肌发展的王牌动作。**手肘不要打得太开（90°）**——这会给肩关节前侧巨大压力。保持肘部与身体 45-60°。

---

### 🟦 A2. 器械上斜推胸（Incline Chest Press）— 上胸

![上斜器械推胸](gifs/lever-incline-chest-press.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 推起至上胸肌收紧 |
| **伸展** | 慢速回程，上胸被拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 8-10 次 |
| **RPE** | 7-8 |
| **角度** | 30-45° |
| **组间休息** | 75-90 秒 |

**动作讲解**：
1. 使用上斜推胸器械，角度约 **30-45°**
2. 调整座椅使握把与上胸对齐
3. 发力轨迹朝向前上方，推到顶端感受**上胸肌**收缩
4. 回程控制，不要借助反弹力

> 🎯 **重点关注**：久坐族的上胸普遍偏弱。上胸练好了，侧面看胸部更饱满，体态也更挺拔。**角度不要超过 45°**——角度太高会变成练肩前束。

---

### 🟪 B1. 龙门架直杆下压（Straight Bar Tricep Pushdown）— 三头

![绳索下压](gifs/cable-tricep-pushdown.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 手臂伸直下压，三头肌收紧 |
| **伸展** | 回程至前臂约 90°，感受三头肌拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 10-12 次 |
| **RPE** | 7-8 |
| **握法** | 正握直杆 |
| **组间休息** | 60 秒 |

**动作讲解**：
1. 站于高位龙门架前，正握直杆
2. **肘部紧贴身体两侧**，下压至手臂伸直
3. 顶峰停顿 1 秒，挤压三头肌
4. 回程时前臂回到约 90°，不让配重片落下
5. **全程肘部不移动**

> 🎯 **重点关注**：肘部前后摆动就是借力。**肘部固定是唯一要点**。直杆比绳索更适合上大重量。

---

### 🟪 B2. 过顶三头臂屈伸（Overhead Tricep Extension）— 三头长头

![绳索过头臂屈伸](gifs/cable-rope-overhead-tricep.gif)

| 阶段 | 说明 |
|------|------|
| **收缩** | 手臂从颈后向前伸展，三头肌长头收紧 |
| **伸展** | 慢速回程，三头肌长头被充分拉伸 |

| | |
|------|------|
| **组数 × 次数** | 4 组 × 10-12 次 |
| **RPE** | 6-8 |
| **组间休息** | 45-60 秒 |

**动作讲解**：
1. 背对龙门架，双手拉绳索过头（可用哑铃替代）
2. 从颈后向前伸展手臂，感受**三头肌长头**的收缩
3. 手臂伸直后停顿 1 秒
4. 慢速回到起始位

> 🎯 **重点关注**：长头是三头肌中体积最大的部分。**不要用太重**，否则容易耸肩借力。这个动作也能很好地拉伸三头肌长头。

---

## 三、练后拉伸（5 分钟）

> 目标：放松胸肌、肩前束，打开胸腔，对抗圆肩

### 3.1 胸部拉伸

![胸部动态拉伸](gifs/dynamic-chest-stretch.gif)

| 阶段 | 说明 |
|------|------|
| **拉伸** | 双手向后展开，胸部向前挺，感受胸大肌拉伸 |

- **保持 30 秒 × 2 组**

### 3.2 胸部与肩前拉伸

![胸部与肩前拉伸](gifs/chest-shoulder-stretch.gif)

| 阶段 | 说明 |
|------|------|
| **拉伸** | 手扶墙/门框，身体前倾旋转，胸肌和肩前束被拉长 |

- 手扶墙或门框，身体前倾旋转
- 感受胸肌和三角肌前束的拉伸
- **每侧保持 30 秒 × 2 组**

> 🎯 推日后胸肌拉伸**极其重要**！紧张的胸肌会加重圆肩。**多做 1 组拉伸，比多练 1 组推胸更有价值**。

### 3.3 三头肌拉伸

- 手臂上举，屈肘，用另一只手拉肘部向后
- 感受三头肌长头的拉伸
- **每侧保持 30 秒 × 2 组**

---

## 📌 胸+肱三头日小贴士

- **肩部保护第一**：推胸时肩关节不适 → 立刻停止，降重量或改器械
- **手肘角度**：杠铃推胸时手肘与身体保持 45-60°，不要打开到 90°
- **胸肌拉伸**：推日后紧张的胸肌会加重圆肩，**拉伸比训练更重要**
- **前束说明**：推胸动作已充分刺激肩前束，第四天肩日会进一步强化
- **呼吸**：推起时呼气，下放时吸气
- **渐进超负荷**：记录每次杠铃推胸的重量和次数，下次争取突破
