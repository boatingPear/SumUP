# 个人护肤

## 当前产品

- 适乐肤 (CeraVe) 10% 纯维C精华
- 理肤泉 (La Roche-Posay)绿标防晒
- 适乐肤 (CeraVe) A醇精华 (蓝瓶)
- 适乐肤 (CeraVe) PM乳
- 上水和肌水杨酸2%

## 使用细节

### 第一阶段：新手耐受期（第 1 - 4 周）

**核心目标：** 让皮	肤认识维C、A醇和水杨酸。**严防红肿、脱皮。**

| **星期** | **晨间流程 (防御)**            | **晚间流程 (适应)**           | **重点细节**                 |
| -------- | ------------------------------ | ----------------------------- | ---------------------------- |
| **周一** | 洁面 + **PM乳** + 绿标防晒     | 洁面 + **PM乳** + **A醇**     | **乳液打底**：降低 A醇渗透压 |
| **周二** | 洁面 + **PM乳** + 绿标防晒     | 洁面 + **PM乳 (厚涂)**        | **纯修护**：不加任何精华     |
| **周三** | 洁面 + **维C(2滴)** + **PM乳** | 洁面 + **PM乳** + **A醇**     | 维C少量试探，避开伤口        |
| **周四** | 洁面 + **PM乳** + 绿标防晒     | 洁面 + **PM乳 (厚涂)**        | 停药日，观察是否起皮         |
| **周五** | 洁面 + **维C(2滴)** + **PM乳** | 洁面 + **水杨酸(仅点涂鼻翼)** | 水杨酸只针对黑头，不全脸     |
| **周六** | 洁面 + **PM乳** + 绿标防晒     | 洁面 + **PM乳** + **A醇**     | 尝试一周内第 3 次 A醇        |
| **周日** | 清水洗脸 + **PM乳**            | 洁面 + **PM乳 (全脸厚涂)**    | 给皮肤自我修复的时间         |

### 第二阶段：高效发力期（第 2 - 4 个月）

**核心目标：** **淡化印子、平滑肤质。** 此时皮肤已耐受，可以让功效成分直接接触皮肤。

| **星期** | **晨间流程 (亮肤)**              | **晚间流程 (代谢)**                | **重点细节**             |
| -------- | -------------------------------- | ---------------------------------- | ------------------------ |
| **周一** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **A醇** + **PM乳**          | A醇直接上脸，改善痘坑    |
| **周二** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **水杨酸(局部)** + **PM乳** | 重点清理T区和闭口        |
| **周三** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **A醇** + **PM乳**          | 坚持抗氧，预防印子变黑   |
| **周四** | 洁面 + **PM乳** + 绿标防晒       | 洁面 + **PM乳 (加量)**             | **必须保留**的停药缓冲日 |
| **周五** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **A醇** + **PM乳**          | 保持高频代谢，细化肤质   |
| **周六** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **水杨酸(全脸/局部)**       | 一周一次深度清理角质     |
| **周日** | 清水洗脸 + **PM乳** + 防晒       | 洁面 + **PM乳 (厚敷)**             | 缓解一周积累的干燥感     |

### 第三阶段：高阶维持期（第 5 个月以后）

**核心目标：** **极致细腻、改善痘坑边缘。** 适合已经成为“城墙皮”的你。

| **星期** | **晨间流程 (极致抗氧)**          | **晚间流程 (深度磨皮)**            | **重点细节**             |
| -------- | -------------------------------- | ---------------------------------- | ------------------------ |
| **周一** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **A醇** + **PM乳**          | 持续刺激胶原蛋白         |
| **周二** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **A醇** + **PM乳**          | **连用两晚**：强化代谢   |
| **周三** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **水杨酸(全脸)** + **PM乳** | 全脸抛光，告别暗沉       |
| **周四** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **A醇** + **PM乳**          | A醇频率提升至 4 次/周    |
| **周五** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **A醇** + **PM乳**          | 追求皮肤的“透亮感”       |
| **周六** | 洁面 + **维C** + **PM乳** + 防晒 | 洁面 + **水杨酸(全脸)** + **PM乳** | 强力磨平角质不平整       |
| **周日** | 清水洗脸 + **PM乳**              | 洁面 + **PM乳 (极厚涂)**           | **高强度后必须彻底修复** |



























































| **星期** | **晨间流程 (防御+亮肤)**                 | **晚间流程 (代谢+修护)**                 | **护肤重点**                 |
| -------- | ---------------------------------------- | ---------------------------------------- | ---------------------------- |
| **周一** | 洁面 + **维C** + **PM乳(薄)** + 绿标防晒 | 洁面 + **A醇** + **PM乳(厚)**            | 开启一周胶原蛋白再生         |
| **周二** | 洁面 + **维C** + **PM乳(薄)** + 绿标防晒 | 洁面 + **水杨酸(局部)** + **PM乳**       | 清理黑头、闭口，控油         |
| **周三** | 洁面 + **维C** + **PM乳(薄)** + 绿标防晒 | 洁面 + **A醇** + **PM乳(厚)**            | 针对痘坑边缘进行“磨边”       |
| **周四** | 洁面 + **PM乳** + 绿标防晒 (停VC)        | 洁面 + **霏丝佳** (停所有功效精华)       | **皮肤喘息日**，深度强韧屏障 |
| **周五** | 洁面 + **维C** + **PM乳(薄)** + 绿标防晒 | 洁面 + **A醇** + **PM乳(厚)**            | 强化抗氧与紧致效果           |
| **周六** | 洁面 + **维C** + **PM乳(薄)** + 绿标防晒 | 洁面 + **水杨酸(全脸/局部)** + **PM乳**  | 深度大扫除，细致毛孔         |
| **周日** | 清水洗脸 + **PM乳** (+ 绿标防晒)         | 洁面 + **PM乳** + **理肤泉B5(点涂印子)** | 集中淡化红印，准备下一周     |
