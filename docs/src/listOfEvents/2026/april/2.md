# 二号的流水账

::: tip 《七律·长征》毛泽东

红军不怕远征难，万水千山只等闲。

五岭逶迤腾细浪，乌蒙蓬勃走泥丸。

金沙水拍云崖暖，大渡桥横铁索寒。

更喜岷山千里雪，三军过后尽开颜。

-----

红军全然不畏惧长征路上的一切艰难困苦，把经历的万水千山都看得极为平常。

绵延起伏的五岭山脉，在红军眼中不过是翻腾的细小波浪；气势雄伟的乌蒙山，在红军看来也只是脚下滚动的小泥丸。

金沙江湍急的江水拍击着高耸入云的山崖，水汽蒸腾，让人倍感温暖；大渡河上的泸定桥横跨两岸，只剩冰冷铁索，令人心生寒意。

更让人欣喜的是，红军翻越了千里积雪的岷山，全军将士过后个个笑逐颜开。

:::
