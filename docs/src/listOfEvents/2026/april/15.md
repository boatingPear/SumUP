# 十五号的流水账

::: tip 《七律·长征》毛泽东

红军不怕远征难，万水千山只等闲。

五岭逶迤腾细浪，乌蒙磅礴走泥丸。

金沙水拍云崖暖，大渡桥横铁索寒。

更喜岷山千里雪，三军过后尽开颜。

-------------

红军将士不怕远征的困难，走千山万水也不算什么。

绵延起伏的五岭山脉，在红军眼中不过是翻腾的细小波浪；乌蒙山磅礴的其实在红军眼中就是小泥丸一般。

金沙江水拍山崖，激起的水雾感觉很温暖一样。横渡的大桥铁链真是寒冷。

更喜欢岷山千里的雪景，三军过了之后都会喜笑颜开，表达乐观。
