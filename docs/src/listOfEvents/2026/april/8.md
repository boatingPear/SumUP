::: tip 《梅岭三章·其一》陈毅

断头今日意如何？创业艰难百战多。

此去泉台招旧部，旌旗十万斩阎罗。

-----

- 开篇自问“断头今日意如何”，直面死亡、毫无惧色；

- “创业艰难百战多”：回顾诗妮娜红军征战、九死一生的革命历程；
- “此去泉台招旧部，旌旗十万斩阎罗”：千古绝唱--即便牺牲，也要在阴间召集旧部，率十万大军斩杀阎罗-象征反动势力，展现至死不屈、战斗到底的英雄气概。

:::

1. 在java7及之前，字符串拼接如果没有  变量参与，就预编译
2. 有就会创建新的StringBuilder添加进去
3. StringBuilder源码分析
   1. 默认创建一个长度为16的字节数组
   2. 添加的内容长度小于16的话，直接就存
   3. 添加的内容大于16，扩容原容量 * 2 + 2
   4. 扩容后还不够，就直接扩容到+添加的数量--实际长度
4. 集合 ArrayList
   1. 动态长度
   2. 只能添加引用对象
   3. 基本数据类型就使用对应包装类
