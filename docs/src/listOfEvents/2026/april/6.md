# 六号的流水账

::: tip 《清平乐·六盘山》毛泽东

天高云淡，望断南飞雁。

不到长城非好汉，屈指行程二万。

六盘山上高峰，红旗漫卷西风。

今日长缨在手，何时缚住苍龙？

:::

1. string
   1. 四种构造方法

      2. 穿字符串
      3. 穿字符数组

   2. 比较
      1. 基本数据类型
      2. 引用数据类型

   1. 一般连接字符串
      1. 参数
         1. 连接符
