1. 多态

   1. 对象的多种形态

2. 多态的前提

   1. 有继承/实现关系
   2. 有父类引用指向子类对象
   3. 有方法的重写

3. 多态的好处

   1. 使用父类做参数，可以接收所有子类对象，体现多态的扩展性和便利性。

4. 多态中调用成员的特点

   1. 成员变量：编译看左边，运行也看左边，都有name，使用父的name，父没有就报错
   2. 成员方法：编译看左边，执行看右边，先查找子有没有重写，没有再执行父的方法

5. 多态的优势

   1. 方法中，使用父类型作为参数，可以接收所有子类对象

6. 多态的弊端

   1. 不能使用子类的特有功能，只能根据父类定义的方法进行调用

7. 引用类型数据的类型转换，有几种方式

   1. 自动类型转换、强制类型转换

8. 强制类型转换解决了什么问题

   1. 可以转换成真正的子类类型，从而实现调用子类的特有方法、

   2. 转换类型和实际类型不一致会报错

   3. 转换的使用可以使用`instanceof`关键字进行判断--16后可以一起写

   4. ```java
      Person a = new Student();
      if (a instanceof Student b) {
          // 在这就是如果a是Student类型，那么就转换为这个类型，且重新赋值给变量b
      }
      ```

9. final：

   1. 修饰方法：最终方法，不能被重写
   2. 修饰类：最终类，不能被继承
   3. 修饰变量，是常量，不能被修改
      1. 基本数据类型不能修改
      2. 引用数据类型是地址不能改，但地址指向的对象可以改

10. 代码块

    1. 局部代码块：定义的都是局部变量，执行完就销毁了
    2. 构造代码块：抽取构造方法中的公共逻辑，在每次执行构造方法的时候执行，在构造方法执行前执行
    3. 静态代码块：在类加载时执行，一般用来初始化，只执行一次

11. 抽象类和抽象方法

    1. 包含抽象方法的类一定是抽象类
    2. 抽象类中的方法不一定是抽象方法
