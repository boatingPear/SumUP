# 十八号的流水账

1. 泛型：参数化类型
   1. 细节：因为java文件在编译时会转换成class文件，这时会擦除泛型，但泛型的基础类是Object类，而基本数据类型int不是Object的子类，没法自动转，而泛型需要Object来实现通用化，利用了多态的特性
   2. 泛型类
      1. 在类的定义中使用泛型类型参数的类
   3. 泛型方法
      1. 在方法定义中使用泛型类型参数的方法
   4. 泛型接口
      1. 在接口的定义中使用泛型类型参数的接口
   5. 通配符？
      1. `<? extends E>`：表示可以传递E或者E所有的子类类型
      2. `<? super E>`：表示可以传递E或者E所有的父类类型
      3. 泛型不具备继承性，数据具备继承性
2. 知识加油站
   1. 数据结构
      1. 栈：先进后出
      2. 队列：先进先出
      3. 数组：查找很快，但插入删除就慢了
      4. 链表：增删快，插入慢，时间辐照度O(n)
         1. 链表节点都是独立的，在内存在都是不连续的
      5. 数：
         1. 二叉树
            1. 节点和度，度最大不超过2，查找比链表快，但如果只有一条子树，那就和链表是一样了
         2. 二叉查找树
            1. 度最大不超过2
            2. 任意节点上左子树的节点都小于当前节点
            3. 任意节点上右子树的节点都大于当前节点
         3. 平衡二叉树
            1. 会根据规则自平衡
            2. 高度差最大不能大于1
            3. 任意节点到的子树都有个平衡二叉树
            4. 旋转：
               1. 左旋：右节点变成根节点，原根节点作为新根节点的左子树，原右节点的左子树，拆给原根节点(现左节点)作为右子树
               2. 右旋：左节点变成根节点，原根节点作为新的根节点的左子树，原左节点的右子树，拆给原根节点(现右节点)作为左子树
         4. 红黑树
            1. 每个节点都有颜色标记，只能是红色或黑色
            2. 红色不能相连，如当前节点时红色，那么父节点和子节点就不能是红色
            3. 每个节点都还有自己的两个`Nil`空叶节点，叶节点是黑色的
            4. 根节点永远是黑色的
            5. 从任意节点触发，任意叶节点，经过的黑节点都是相等的
   2. 可变参数：`数据类型...数据名称`：不确定需要接收多少参数时使用
   3. lambda表达式：算是个语法糖，在抽象类实现函数式接口时使用，函数式接口是只有一个抽象方法的接口。
3. 函数式接口：只包含一个抽象方法的接口
4. Equals()方法和==运算符的区别
   1. ==其实就是直接在栈中的值
      1. 基本数据类型，如：int boolean 或者 "" 在栈中存的是值
      2. 引用数据类型存储的是地址：所以两个引用数据类型内部的值一样，但地址不一样也不相等
   2. equals对比两个对象的值是否相等，可以做规则的重写
