# 二十九号的流水账

做饭，蒜台辣椒炒猪头肉

​	今天在家洗衣服收拾的时候，被朋友叫去吃饭，本来我是真不想去的，是想收拾好后，在家学习，但实在是架不住他老是叫，甚至我刚把衣服放到洗衣机，还有三十多分钟才能洗完，都被叫走，说直接回来再拿也一样。老是这样吗，打完措手不及，我不喜欢没有准备的行动。

​	当然，这也导致了我养成了另一个问题，有点拖延。不过我感谢今天的拖延，摩了我很久后答应了去吃饭，我放下了手下的其他活，开始我出门前的必修课（出远门，附近买菜活简单吃饭不会），洗个头，抓抓造型，找身衣服，看着有点脏又开始刷鞋。这才出发，机会果然是留给有准备的人的。

​	闯开车有点太猛，下次还是尽量让王耀开车吧。

​	这家店很久没吃了，性价比确实很不错，味道也行，比较大的问题就是我感觉卫生有点不太达标，解决了这个他真的可以开分店了，就是不知道老板能不能挣钱，毕竟活鱼自助才35一位。

​	吃完王耀提议去路过看到的疑似服装商场的地方去逛逛，其实是他看错了，附近没有。还是想去，就在导航软件上随便找了个还在营业的，驱车前往，我到现在都感觉十分庆幸，先去了比较大的那个商场-中国服装品牌孵化基地，买了几件帅气的衣服后，出来了，我又想买一条裤子，王耀提议回去，王闯提议可以去旁边的

衣佳汇服装批发市场去看看，进来了就看见他了，真的很漂亮，很和我眼缘，有种复古美女的感觉，可能是他的烫发吧，哈哈。

​	有点忧郁的气质，甚至有点破碎感，不知道是不是上班太晚了有点累，毕竟都八点了。然后开始和他们逛，当然很正常的逛，只是觉得这女孩长的很舒服。然后逛完了往回走，又看见了，偷偷看了看，嗯确实挺好的。我说那边那个女生长的挺好看，他两又上劲了，说买两双袜子，开始挑袜子，他在旁边叠衣服，内心里其实已经是想怎么找机会给他说说话，到最后有没说话，付钱的时候站在王闯旁边又看他，不过是正大光明的看，反正又不犯法， 她可能是有感应有人再看他，她抬头了，我俩有了一瞬间的眼神交流，心里有说了一句不错，然后就走了。

​	就在门口快走的时候我突然想要微信了，因为真的他长在我审美上了，应该是我现实见过不是最好看，但最舒服的。就突然想要微信，让后我直接说了， 他俩就说去要就是，因为不出意外这就是这辈子见的最后一面了，就算后面隔了一段时间后再见，其实也是相当于新见面了，因为肯定都没有印象了。当然，他两两个单身狗遇见了自己喜欢的女孩也不一定干，理论嘛，那可能是头头是道。

​	往回走，在门口扭捏了相当就，问我该怎么说，问能加微信吗，加完之后再怎么说，王闯说直接走就行，可我还老是觉得会不会太冷，因为你主动找人家，然后还不说句话直接走，不太好，至少给她的印象不会太好吧，我去我记的可真够清晰的。最后敲定说你先忙，回头再聊，就走了。还没先同意就迫不及待的看朋友圈。 又证明了我的眼光果然没错，很质朴，没有花里胡哨的东西，好像也是个农村孩子。看看了看后，想着还是先同意，说不定他还再看，老是不同意算怎么回事。又坏了，我同意了我好像看不了她的朋友圈了，为啥，又想坏了，是不是给我屏蔽了，在加好友的时候选择了仅聊天。还好重新进了一下能看了上车回家。

​	在路上开始细细的看她的朋友圈，试图了解她，也想找找等会能聊的话题。还减肥，哎不瘦啊。年龄我俩应该差不多，因为23年还在宿舍吃饭，后面还说我聪明，哈哈。

​	等他下班后回消息了又二十分钟我每回复他消息，因为我的老毛病又犯了，不知道说啥，要不也不能单身到现在。不过总算开启了话题，不是很好，但对我来说总算是开头了，希望能把握住她，因为我真的感觉，人这一辈子其实遇不到几个很和眼缘的，还是把握住。写着写着凌晨一点零八了，还给人家说睡饱觉，养好身体很重要呢，自己都没做到。

​	就先写到这把，今天可能真是算我的重要人生节点了。--睡觉
