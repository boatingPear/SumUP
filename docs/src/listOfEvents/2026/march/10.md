1. Math类：进行基本的数学运算
   1. abs 取整
   2. ceil 小数向上取整，返回的类型还是小数（2.0)
   3. floor 小数向下取整，返回的类型还是小数(2.0)
   4. round 四舍五入 return int
   5. max 对比返回大的
   6. min 对比返回小的
   7. pow 指定数的几次幂计算2^3
   8. random 返回一个[0,1)的随机数
2. System类：包含操作系统的一些常用方法
   1. currentTimeMillis() 获取当前时间对应的时间戳，可以用来计算代码执行了多久
   2. exit 终止jvm虚拟机(0)表示终止的状态，是正常退出
   3. arraycopy 复制a数组中从指定索引开始的值，到b数组的指定索引
3. Runtime 表示java虚拟机的运行时对象，可以获取程序运行信息
   1. getRuntime 获取虚拟机对象实例
   2. exit 停止虚拟机
   3. availableProcessors 获取当前设备的cpu线程数
   4. maxMemory jvm能从系统中获取的最大内存数，单位比特(byte)
   5. totalMemory jvm已经从系统中分配到的最大内存数
   6. freeMemory 已经从系统中分配的内存中，剩余没使用的部分
   7. exec 运行cmd命令
4. Object（重点）Object类是所有类的根类
   1. toString 返回对象的字符串表现形式，输出的就是指向对象存储内存的地址的哈希字符串
   2. equals(Object obj) 比较两个值是否相等，如果是引用数据类型其实对比的是地址了
   3. clone 拷贝对象---其实是浅拷贝 
      1. 深拷贝可以用gson.toJson() 再fromJson就可以，和js差不多
5. Objects类：主要用来操作对象
   1. equals 先做非空判断，比较两个对象
   2. isNull判断是否为空
   3. nonNull 如果提供的引用为非`null`则返回`true`，否则返回`false`。
6. BigInteger 再int取值范围不够用时使用
   1. BigInteger add  加
   2. BigInteger subtract 减
   3. BigInteger multiply 乘
   4. BigInteger divide 除
   5. BigInteger[] divideAndRemainder 除，同时获取商和余数
   6. equals 比较是否相同
   7. pow 次方
   8. max/min 比较返回较大/较小值
7. BigDecimal类 主要是解决浮点数计算的精度问题
   1. 0.09+0.01=0.09999999999999999999
   2. valueOf 获取BigDecimal对象
   3. add 加法
   4. subtract 减法
   5. multiply 乘法
   6. divide 除法
8. SimpleDateFormat类 是日期/时间格式化类，可以实现Date对象和String对象的转换   JAVA7的
   1. y M d H m s 年月日时分秒
   2. String format(Date date); 将Date对象格式化为字符串
   3. Date prase(String source); 将字符串解析为Date对象
9. Calendar类（重点）是个日历类，而且是个抽象类，不能创建对象，用来做日历的计算很好用，一般用它的子类
   1. GregorianCalendar类
   2. getInstance 获取实例对象
   3. getTime 是获取时间戳
   4. get获取指定信息的，传递的是自己的常量
   5. Calendar.YEAY 获取日历对象的年份
   6. Calendar.MONTH
   7. Calender.DAY_OF_MONTH 当前月份的第几天
   8. add日期计算
   9. Calendar.getInstance().getTime();calendar转换为date格式
10. ZoneId时区 表示时区的类。可以偏移计算，可以获取对应的时区信息
11. Instant 时间戳类 
    1. 判断什么时候在什么时间的前面还是后面比较好用
12. ZonedDateTime 带时区的时间
13. DateTimeFormatter 用于时间的格式化和解析
    1. ofPattern 获取指定格式的格式化实例对象
    2. format 按照指定方式格式化
14. LoclDateTime处理本地日期时间
    1. 他的两个子类分别是LocalDate和LocalTime
    2. 都是线程安全的，可以在多线程环境中使用。
    3. .now()获取当前日历时间
    4. of(2023,1,1)获取指定的日期对象
    5. getYear ....能获取当月的第几天和当年的第几天
    6. isbefore和isAfter 可以判断日期是否在指定日期的前或后
    7. with修改日期，只能修改年月日
    8. minus减少，只能修改年月日
