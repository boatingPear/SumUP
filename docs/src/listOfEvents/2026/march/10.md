1. Math类：进行基本的数学运算
   1. abs 取整
   2. ceil 小数向上取整，返回的类型还是小数（2.0)
   3. floor 小数向下取整，返回的类型还是小数(2.0)
   4. round 四舍五入 return int
   5. max 对比返回大的
   6. min 对比返回小的
   7. pow 指定数的几次幂计算2^3
   8. random 返回一个[0,1)的随机数

2. System类：包含操作系统的一些常用方法
   1. currentTimeMillis() 获取当前时间对应的时间戳，可以用来计算代码执行了多久
   2. exit 终止jvm虚拟机(0)表示终止的状态，是正常退出
   3. arraycopy 复制a数组中从指定索引开始的值，到b数组的指定索引
3. Runtime 表示java虚拟机的运行时对象，可以获取程序运行信息
   1. getRuntime 获取虚拟机对象实例
   2. exit 停止虚拟机
   3. availableProcessors 获取当前设备的cpu线程数
   4. maxMemory jvm能从系统中获取的最大内存数，单位比特(byte)
   5. totalMemory jvm已经从系统中分配到的最大内存数
   6. freeMemory 已经从系统中分配的内存中，剩余没使用的部分
   7. exec 运行cmd命令
4. Object（重点）Object类是所有类的根类
   1. toString 返回对象的字符串表现形式，输出的就是指向对象存储内存的地址的哈希字符串
   2. equals(Object obj) 比较两个值是否相等，如果是引用数据类型其实对比的是地址了
   3. clone 拷贝对象---其实是浅拷贝 
      1. 深拷贝可以用gson.toJson() 再fromJson就可以，和js差不多

5. Objects类：主要用来操作对象
   1. equals 先做非空判断，比较两个对象
   2. isNull判断是否为空
   3. nonNull 如果提供的引用为非`null`则返回`true`，否则返回`false`。
6. BigInteger 再int取值范围不够用时使用
   1. BigInteger add  加
   2. BigInteger subtract 减
   3. BigInteger multiply 乘
   4. BigInteger divide 除
   5. BigInteger[] divideAndRemainder 除，同时获取商和余数
