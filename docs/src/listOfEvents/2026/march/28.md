# 二十八号的流水账

::: tip 行路难·唐-李白

 金樽清酒斗十千，玉盘珍馐值万钱，

停杯投箸不能食，拔剑四顾新茫然。

欲渡黄河冰塞川，将登太行雪满山。

闲来垂钓碧溪上，忽复乘舟梦日边。

行路难，行路难，多歧路，今安在？

长风破浪会有时，直挂云帆济沧海。

--------------

金杯里装着名贵的美酒，一斗就值十千钱；玉盘里乘着珍贵菜肴，价值万钱。

我却放下酒杯，丢下筷子，吃不下东西；拔出剑来，四下张望，心下一片茫然。

想要度过黄河，河水却被坚冰堵塞；想登上太行山，大写早已封山。（比喻人生艰难，到处碰壁）

想到姜太公曾在溪边垂钓；后来遇到周文王；伊尹也曾梦见乘船绕日，后来辅佐商汤。（用古人典故安慰自己，有才之人终会被重用）

人生的路太难走了！岔路这么多，我该往那走？

相信总有一天，我能乘风破浪，扬起大船的帆，横渡沧海，实现理想！
