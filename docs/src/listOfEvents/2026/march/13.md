2. 遍历集合的几种方式
   1. 迭代器：Iterator
      1. Collection.iterator() 返回迭代器的示例对象
      2. 成员方法
         1. hasNext() 下一个索引是否还有元素
         2. next() 获取当前索引元素作为返回值，然后在索引加1
         3. 遍历完成后指针不会重置
      3. 警告：迭代器遍历时， 不能用集合的方法删除，必须用迭代器的方法删除

   2. 增强for循环

      1. ```java
         for(类型 变量名 : 集合名称) {
             sout(变量名) // 正常使用就可以
         }
         ```

      2. 修改增强for中的变量不会改集合的数据，因为是重新创建接收的

   3. lambda表达式

      1. 有点像js里的箭头函数

      2. ```java
         list.forEach((s) -> {
             sout(s)
         })
         ```

      3. 如果实现类只需要重写一个抽象方法，那么这个抽象方法名也可以省略
