在每天流水账的开头，先给自己打个鸡血，或抄个诗，后面可以重复，没有月不能重复；



1. 异常处理
   1. 分类：
      1. 编译时期异常：checked异常
      2. 运行时期异常：runtime
   2. 异常捕获：`try...catch`
      1. 写多个对应的catch
   3. 异常常用方法
      1. getMessage 返回词报错的具体信息详情字符串
      2. toString 返回此错误的可抛出的剪短描述
      3. printStackTrace 将异常信息在控制台输出
   4. throws 异常生命关键字，在定义类时写
   5. throw 抛出异常关键字
   6. 自定义异常类
      1. 带参构造
      2. 空参构造
   7. finally 只要不主动调用系统终止的方法，都会执行
2. File类
   1. 构造方法
      1. public File(String pathname)  根据文件路径创建文件对象
      2. public File(String parent, String child) 根据父路径字符串和子路径字符串创建文件对象
      3. public File(File parent, String child) 根据父路径对应文件对象和子路径字符串创建文件对象
      4. 都是创建File对象，每个File对象在硬盘中都真实存在一个文件或目录
   2. 常用成员方法
      1. isDirectory 判断此路径名表示的是文件夹吗
      2. isFile 判断指定路径的File是文件吗
      3. exists 指定路径的File是否存在
      4. long 返回大小-字节数
      5. getAbslutepath 返回文件的绝对路径
      6. getPath 返回定义文件时使用的路径
      7. getName 返回文件的名称，带后缀
      8. lastModified 返回文件的最后修改时间（毫秒）
