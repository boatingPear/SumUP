# 十六号的流水账

1. List集合
   1. 存取有序
   2. 可以重复
   3. 有索引
2. ArrayList集合
3. LinkedList集合
   1. 双向链表实现类，可以用来存储一组有序的元素。
   2. 所有的node都包含了指向当前，前一个，后一个元素的指针
4. Set集合
   1. 无序
   2. 不重复
   3. 无索引
5. HashSet集合
   1. 根据hashCode方法算出来的int类型的整数
6. LinkedHashSet集合
   1. 有序
   2. 不重复
   3. 无索引
7. Set 不能重复，无索引的集合
8. Map key不能重复，无索引的键值对对象的集合
9. 如果想要集合中的元素可重复
   1. 用ArrayList集合，基于数组的（用的最多）
