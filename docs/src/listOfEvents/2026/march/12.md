1. 包装类

   1. int的包装类是Integer
   2. char的包装类是Character

2. 集合类

   1. 单列集合和双列集合
   2. 单列就是ArrayList,set
   3. 双列就是map
   4. Collection是单列集合的祖宗接口
      1. add 添加元素
      2. remove 移除元素
      3. removeIf 根据条件移除元素
      4. claer 清空元素
      5. contains 判断指定元素是否在集合中
      6. isEmpty 判断集合是否为空
      7. size 获取集合的长度

3. 常用类

   1. String
      1. new String("a") // 直接用""引号创建
      2. new String(char[])// 用字符数组创建，默认就是拼接
      3. new String(byte[]) // 用字节数组创建，默认是字节码
      4. String s = "sss" 
   2. 字符串的比较
      1. ==是只比较值，而引用数据类型，变量中存储的是引用地址
      2. string可以用equals比较值
      3. replace和replaceAll和js中用法一直
   3. StringBuilder 可以看做是个字符串的容器，和String不同的是可以更改
      1. 方法：append  添加，到尾部或者指定索引
      2. reverse 反转字符串
      3. .length() 获取字符串长度

4. 枚举 一组常量的集合

   1. 可以只有属性

   2. 也可以同时有键和值

   3. 枚举其实就是特殊的类

   4. 变量其实就是在加载的时候就调用有参构造创建的对象

   5. 枚举值也可以实现接口

   6. 实现接口时也可以重写方法
